# Stack

Implement a generic `Stack<E>` in Java in two variants:

- `ArrayStack<E>` – array-backed, grows dynamically.
- `LinkedStack<E>` – singly-linked-list-backed.

Both must satisfy the `Stack<E>` interface (`push`, `pop`, `peek`, `size`, `isEmpty`, `clear`).

## Notes

- Add tests in `StackTest`.

## Run

```bash
mvn test
```

Java 17+, Maven.
